# Chapter 1: Introduction and Adobe Reader

## Introduction

Your RealtyJuggler membership comes with a number of flyer templates suitable for listings, open houses and other needs.

The templates are in Adobe PDF format and can be edited and saved using Adobe Acrobat Reader. To create a flyer, replace the sample text and photos with your own. RealtyJuggler handles page layout and photo scaling automatically, so a professional flyer takes just minutes to create.

You can print your flyer on your own printer or at any print shop. You can also save it as a PDF file for emailing or posting to your own website and social media.

## Adobe Reader

RealtyJuggler flyers require Adobe Reader 9.0 or later to edit and view flyers. You can download this free application from Adobe: https://get.adobe.com/reader/

> Image: Small red Adobe Acrobat icon (a white stylized "A" on a red rounded square), shown beside the opening sentence to indicate the Adobe Reader requirement.

To find out which version of Adobe Reader you have, click the Help menu and select "About Adobe Acrobat…". Make sure you have version 9.0 or later. If you have an earlier version, download and run the installer from the Adobe website.

### Macintosh Users

> Image: Macintosh Finder icon (a blue-and-white smiling face) with the word "Mac" beneath it, marking the section as Mac-specific.

Make sure you are using the latest version of Adobe Acrobat Reader. You cannot use the "Preview" application to edit your PDF flyers. If the flyer opens in Preview, follow these steps to redirect .pdf files to Adobe Reader:

1. Find the .pdf file you downloaded in Finder and right-click it (control-click).
2. Select the Get Info menu item.
3. Select the Open With option and choose Adobe Reader as the application that should be used for PDF files.
4. Click the "Change All…" button.

> Image: Screenshot of the macOS Get Info "Open with:" section. A dropdown shows "Adobe Reader" selected, with the text "Use this application to open all documents like this one." and a "Change All…" button beneath it. This illustrates steps 3 and 4.

### Windows PC Users

To make sure flyers are opened within Adobe Reader:

1. Download a flyer to the desktop of your hard drive.
2. Right-click the flyer to bring up a menu.
3. Select "Properties."
4. Click the "Change" button next to "Opens with:".
5. Select "Adobe Acrobat".
6. Click the "Set Default" button.
7. Click "OK".

> Image: Screenshot of a Windows file Properties dialog for a file named "017.pdf". The General tab is active (other tabs: Digital Signatures, Security, Details, Previous Versions). It shows the file name, "Type of file: Adobe Acrobat Document (.pdf)", and "Opens with: Adobe Acrobat" with a "Change…" button. This illustrates steps 4 and 5.

## Downloading a Flyer

Go to the Main:Flyers section of RealtyJuggler and browse the flyer templates. Click a template to download it. Once it is on your hard drive, open it using Adobe Reader. You can then edit the flyer and print it.

Important: Do NOT open the flyer within your web browser. You MUST download the flyer to your hard drive and open it using Adobe Reader. If you open the flyer in your browser it will NOT be editable.
